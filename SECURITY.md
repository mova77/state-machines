# Security policy

## Reporting a vulnerability

Please report vulnerabilities through GitHub's private vulnerability reporting, using the **Report a vulnerability** button on the [Security tab](https://github.com/mova77/state-machines/security) of this repository. Please do not open a public issue for a security problem.

You can expect an acknowledgement within a few days. A fix and an advisory will follow once the report is confirmed.

## Supported versions

Only the latest released version receives security fixes.
